# 🛒 ديوان ماركت – فرع البداوي
## نظام متابعة الصالة وتسليم الورديات اللحظي (Diwan Market Operations & Shift Handover)

نظام ويب تشغيلي متكامل لفرع البداوي – ديوان ماركت، يهدف إلى تنظيم ومتابعة أعمال الصالة والأقسام المختلفة وتنسيق تسليم واستلام الورديات (Shifts) بين مسؤولي الصالة دون الحاجة إلى تشغيل أي سيرفر دائم وبدون الاعتماد على واتساب.

---

### ✨ المميزات الرئيسية

1. **نظام تسليم واستلام الورديات (Shift Handover):**
   - نقل المهام العالقة وغير المنجزة آلياً إلى المشرف في الوردية التالية.
   - بانر استلام تفاعلي يُبرز للمشرف الجديد كل ما تركه سلفه ليكمله فور دخوله.
   - توثيق أسماء المشرفين وساعة التسليم وتأكيد الاستلام.

2. **حالات تشغيلية متطورة لكل مهمة (59 بنداً عبر 10 أقسام):**
   - ✅ **منجز (Done):** تم الفحص والأمور مطابقة.
   - 🔄 **قيد العمل (In Progress):** المشرف يعمل عليها حالياً.
   - ⚠️ **للوردية القادمة (Handover):** مرحلة مع سبب الترحيل.
   - 🚨 **خلل طارئ (Critical):** أعطال أو مشاكل صيانة.

3. **سجل درجات حرارة الثلاجات الذكي:**
   - فحص آلي للنطاق الآمن لثلاجات الألبان واللحوم والدواجن والمخبز.
   - إشارات تنبيه حمراء عند تجاوز الحدود الطبيعية.

4. **تزامن لحظي متعدد الطبقات:**
   - تزامن محلي فوري بين التبويبات بدون أي خادم (\BroadcastChannel\).
   - حفظ تلقائي غير متصل (\LocalStorage\) لمنع فقدان البيانات.
   - دعم التزامن السحابي عبر **Google Firebase Realtime Database** مجاناً 100%.

5. **أرشيف الورديات والطباعة الرسمية:**
   - استعراض سجل الورديات السابقة.
   - طباعة تقرير يومي بتنسيق A4 أنيق مع خانات الاعتماد والتوقيع للإدارة.
